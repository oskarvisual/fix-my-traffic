# Roadmap

1. **Complete now:** Lima map, simulated congestion, road inspection, bike-lane construction, demand redistribution and IndexedDB recovery.
2. Import and normalize versioned OSM data; add a replaceable `TrafficDataProvider` and shared Supabase city catalogue.
3. Add BRT and metro project implementations with staged construction.
4. Add procurement, contractors, audits and delayed corruption events.
5. Add approval polling, terms, elections and game-over states.

The map and domain model support expansion, but only the first loop should be balanced before later systems are added.
